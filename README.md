# Actors Website – Projet d'apprentissage

## 📌 À propos du projet

Ce projet a été réalisé dans le cadre de mon apprentissage du développement web front-end.

L'objectif était de mettre en pratique les connaissances acquises en HTML, CSS, Bootstrap et jQuery à travers la création d'un site web consacré aux acteurs.

Ce projet m'a permis d'expérimenter la création d'interfaces web, la mise en page responsive et l'ajout d'interactions dynamiques.

## 🛠️ Technologies utilisées

- **HTML5 :** structuration des pages et organisation du contenu.
- **CSS3 :** personnalisation du design et mise en forme des éléments.
- **Bootstrap :** création de mises en page responsives et utilisation de composants prédéfinis.
- **jQuery :** manipulation du DOM et gestion des événements JavaScript.

## 🎯 Objectifs d'apprentissage

- Comprendre et appliquer les bases de la structure HTML.
- Améliorer la maîtrise du CSS pour concevoir des interfaces web.
- Apprendre à utiliser Bootstrap pour adapter un site aux différentes tailles d'écran.
- Découvrir jQuery et ses possibilités pour rendre une page web interactive.
- Développer de bonnes habitudes d'organisation du code.

## 📚 Compétences développées

Ce projet m'a permis de renforcer mes connaissances en développement front-end, de mieux comprendre le fonctionnement des interactions côté client et de pratiquer l'intégration des différentes technologies dans un même projet.
